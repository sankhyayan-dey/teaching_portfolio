## Overview

This website presents my teaching experience, academic background, subjects I teach, and the approach I use to help students understand concepts rather than simply memorise them.

The portfolio is designed to give students and parents a clear overview of my teaching background, areas of specialization, and teaching philosophy.

## Teaching Approach

### Break it down

Complex topics are divided into smaller ideas that students can follow and understand.

### Build understanding

The focus stays on understanding why something works rather than simply remembering what it is.

### Practice independently

Students are encouraged to solve problems themselves after the underlying concept becomes clear.

## Run Locally

### Windows

Clone the repository:

```powershell
git clone https://github.com/sankhyayan-dey/teaching_portfolio.git
cd teaching_portfolio
```

Install dependencies:

```powershell
npm.cmd install
```

Start the development server:

```powershell
npm.cmd run dev
```

The development server will normally be available at:

```text
http://localhost:5173/
```

### Other Platforms

```bash
npm install
npm run dev
```

---

## Build for Production

### Windows

```powershell
npm.cmd run build
```

### Other Platforms

```bash
npm run build
```

The production build is generated in the `dist/` directory.
